# Security

Godart is alpha software and has not undergone an independent security
audit. Functional HTTP, network, and cryptographic APIs do not establish
that an application is secure.

Use the project at your own risk, under the warranty terms in
[LICENSE](LICENSE). Assess the implementation and its dependencies before
use with sensitive data or in security-critical systems.

## Report a vulnerability

Submit a private report through [GitHub Security Advisories](https://github.com/eddyw/godart/security/advisories/new).

Keep credentials, private data, and vulnerability details out of public
issues. The project has no response deadline or support commitment.

## Compatibility

APIs, configuration, and generated output can change.
