# Contributions

Bug reports, questions, and feature requests are welcome through GitHub
Issues. The maintainer currently implements code changes. This project does
not accept external pull requests.

This approach keeps maintenance within the available time and supports a
consistent design while the project evolves. The policy may change.

## Report a problem

Include a small reproduction, the expected result, and the actual result.
Include the Gart or Glutter version, SDK versions, and operating system.
Remove credentials and personal information from code and logs.

For a feature request, describe the problem and the use case.

For a possible security vulnerability, follow [SECURITY.md](SECURITY.md).
